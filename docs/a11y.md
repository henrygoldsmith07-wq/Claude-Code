# Accessibility checklist (Le Studio family)

Applies to every app + every `-site` landing page.

## Per-page requirements
- [ ] Skip link (`<a class="skip" href="#main">Skip to content</a>`) with visible `:focus` state — all `-site` pages have it; Arise `AppShell.jsx` does; Next apps use `AppHeader` with skip where applicable.
- [ ] Header logo `alt="" aria-hidden="true"` (decorative, label in `<b>`); hero image `alt="<App> logo"`.
- [ ] `lang="en-GB"` on `<html>`; `theme-color` meta for light/dark.
- [ ] Focus ring via `a:focus-visible` (all sites) or `le-studio.css` ring tokens.
- [ ] `prefers-reduced-motion` respected (no translateY on reduce).
- [ ] `<title>` ≤60 chars + `<meta name="description">` on every site.

## Per-app requirements
- [ ] Arise: `role=dialog aria-modal` on SessionRunner, `aria-label` on reps inputs, `role=status aria-live=polite` on exercise result counts, `aria-current=page` on nav, backdrop click + Esc to dismiss, touch 44px.
- [ ] Revise/Reflect/World-News/Daily-Debate: `aria-label` on selects/sorts, `aria-hidden` on icons, rate-limit + error `role=alert` where applicable.
- [ ] Keyboard: all primary actions reachable by Tab; no keyboard trap.
- [ ] No `autoFocus` that steals screen reader cursor on load without announcement.

## Validation
- `npm run lint --prefix apps/<app>` must be 0 warnings/errors (enforces `jsx-a11y` via `eslint-config-next`).
- Manual: Tab through each site + one app flow with VoiceOver/TalkBack.

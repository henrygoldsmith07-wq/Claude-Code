### Proposal 3: Pre-authorize routine commits in the pipeline skills
- **What**: In `.claude/skills/data-ingestion/SKILL.md` and
  `.claude/skills/improve-system/SKILL.md`, replace "Do not commit unless the
  user asks" with "When run by a scheduled routine, commit and push to
  `knowledge-base-updates` as the routine prompt instructs; otherwise do not
  commit unless asked."
- **Why**: The skills currently forbid committing while the routine prompts
  require it. A fresh-session run that weighs the skill text over the prompt
  could leave its work uncommitted in an ephemeral container — everything
  ingested that morning would be silently lost when the container is
  reclaimed.
- **Risk**: Minimal — documentation-of-intent change; behavior only changes
  in scheduled runs, which already have commit instructions.
